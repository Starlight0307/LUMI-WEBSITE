개인정보처리방침

시행일: 2026년 11월 5일

Team Build It(이하 "팀")은 LUMI를 쓰는 분의 개인정보를 아래와 같이 처리합니다.

1. 처리하는 정보

  • 계정 정보: 회원가입과 로그인에 쓰는 아이디, 이름, 이메일. Supabase에 저장합니다.
  • 구글 캘린더: 사용자가 연결한 경우에만 일정을 조회·추가·수정·삭제합니다.
  • 애플 캘린더: 사용자가 연결한 경우에만 일정을 조회·추가·수정·삭제합니다.
  • 이 PC에 저장하는 정보: 대화 기록, 설정, 할 일, 메모, 로그인 유지 정보, 연동 토큰, 등록한 IoT 기기 정보. 암호화해 사용자의 PC에만 저장합니다.

2. 이용 목적

회원 식별과 로그인, 사용자가 요청한 일정 관리, 날씨 조회, 기기 제어 등 LUMI 기능 제공에만 씁니다. 광고에 쓰거나 판매하지 않습니다.

3. Google 사용자 데이터

LUMI는 Google 캘린더 API로 받은 정보를 사용자가 요청한 일정 기능을 제공하는 데만 씁니다. 이 정보를 팀의 서버로 보내지 않으며, 다른 사람에게 넘기거나 AI 모델 학습에 쓰지 않습니다. LUMI의 Google API 데이터 사용은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

4. 외부 서비스로 전송되는 정보

  • Supabase: 계정 정보와 로그인 처리
  • Google, Apple: 사용자가 연결한 캘린더의 일정 처리
  • Open-Meteo: 날씨 조회를 위한 지역 이름과 좌표
  • IP 위치 서비스: 기기 위치를 쓸 수 없을 때 현재 지역을 찾기 위한 IP 주소
  • Tuya: Smart Life 기기를 처음 등록할 때 기기 정보 조회
  • GitHub: 새 버전 확인과 업데이트 내려받기

위 경우 외에 개인정보를 제3자에게 제공하지 않습니다.

5. 보관과 삭제

계정 정보는 회원 탈퇴 후 30일 이내에 삭제합니다. 단, 법령에 따라 보존이 필요한 경우는 예외입니다. PC에 저장한 정보는 사용자가 앱에서 지우거나 앱 데이터를 삭제하면 사라집니다. 캘린더 연결은 앱의 [연결 끊기]로 해제할 수 있고, Google 연결은 Google 계정 설정에서도 해제할 수 있습니다.

6. 이용자의 권리

이용자는 언제든지 자신의 개인정보를 조회, 수정, 삭제하도록 요청할 수 있습니다.
