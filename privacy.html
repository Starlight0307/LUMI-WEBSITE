개인정보처리방침

시행일: 2026년 11월 6일

Team Build It(이하 "팀")은 LUMI를 쓰는 분의 개인정보를 아래와 같이 처리합니다.

1. 처리하는 정보

  • 서버에 저장하는 계정 정보: 아이디, 이메일, 이름, 전화번호, 생년월일, 회원번호, 구글·카카오 로그인 연결 정보. Supabase에 저장합니다.
  • 서버에 저장하는 로그인 기록: 로그인 시각, 방식, 기기 종류(예: Windows 11). 컴퓨터 이름은 저장하지 않으며, 로그인 기록에 IP 주소를 따로 적지 않습니다.
  • 캘린더: 사용자가 구글, 애플 캘린더를 연결한 경우에만 일정을 조회·추가·수정·삭제합니다.
  • 이 PC에만 저장하는 정보: 대화 기록, 기억한 내용, 설정, 할 일, 메모, 지출, 앱 사용 기록, 회의록, 주식 즐겨찾기, 로그인 유지 정보, 연동 토큰, 증권사 앱 키, 등록한 IoT 기기 정보. 민감한 항목은 암호화합니다.

2. 이용 목적

회원 식별과 로그인, 계정 보호, 사용자가 요청한 일정 관리, 날씨 조회, 주식 조회와 주문, 기기 제어 등 LUMI 기능 제공에만 씁니다. 광고에 쓰거나 판매하지 않으며, 사용 행태 분석 도구를 쓰지 않습니다.

3. 음성, 화면, 회의 녹음

  • 호출어: 기본으로 켜져 있어, 음성 구성요소를 설치하면 앱이 켜진 동안 마이크가 "루미야"를 기다립니다. 환경설정이나 트레이 메뉴에서 끌 수 있습니다.
  • 음성 인식과 AI 답변: 이 PC 안의 모델로 처리하며 팀의 서버로 보내지 않습니다.
  • 화면 작업: 요청했을 때만 화면을 캡처하고 창의 글자를 읽어 이 PC 안의 모델에 넘깁니다. 화면에 보이는 개인정보도 함께 처리될 수 있습니다.
  • 회의 녹음: 사용자가 시작했을 때만 녹음합니다. 받아쓴 뒤 녹음 파일을 지우고, 글과 요약을 암호화해 이 PC에 저장합니다. 받아쓰기에 실패하면 복구를 위해 녹음 파일을 남깁니다. 녹음 전에 참석자에게 알려 주세요.

4. Google 사용자 데이터

LUMI는 Google 캘린더 API로 받은 정보를 사용자가 요청한 일정 기능을 제공하는 데만 씁니다. 이 정보를 팀의 서버로 보내지 않으며, 다른 사람에게 넘기거나 AI 모델 학습에 쓰지 않습니다. LUMI의 Google API 데이터 사용은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 외부 서비스로 전송되는 정보

  • Supabase: 계정 정보, 로그인 기록, 로그인 처리
  • Google: 구글 로그인, 구글 캘린더의 일정, 이메일 인증 메일 발송
  • Kakao: 카카오 로그인
  • Apple: iCloud 캘린더 연결 시 Apple ID, 앱 전용 암호, 일정
  • 연결한 증권사: 앱 키, 계좌번호, 종목, 주문 내용
  • 공공데이터포털: 계좌 없이 주식 시세를 볼 때 조회한 종목 정보
  • Open-Meteo: 날씨 조회를 위한 지역 이름과 좌표
  • IP 위치 서비스(ipinfo.io, ipwho.is, ip-api.com): 기기 위치를 쓸 수 없을 때 현재 지역을 찾기 위한 IP 주소
  • Hugging Face, Ollama: 음성·AI 모델을 내려받을 때 통신상 전달되는 IP 주소
  • 검색·쇼핑 사이트: 웹 검색과 최저가 검색의 검색어
  • Tuya: Smart Life 기기를 처음 등록할 때 기기 정보 조회
  • GitHub: 새 버전 확인과 업데이트 내려받기

사용자가 해당 기능을 쓸 때만 전송하며, 위 경우 외에 개인정보를 제3자에게 제공하지 않습니다. 일부 서비스는 국외에서 처리될 수 있습니다.

6. 보관과 삭제

회원 탈퇴를 하면 서버의 계정 정보와 로그인 기록을 바로 삭제합니다. 서버 오류로 바로 삭제하지 못하면 로그인을 막아 두고 30일 이내에 삭제합니다. 단, 법령에 따라 보존이 필요한 경우는 예외입니다. 탈퇴하면 이 PC의 대화 기록, 설정, 기억도 함께 삭제합니다. PC에 저장한 정보는 사용자가 앱에서 지우거나 앱 데이터를 삭제해도 사라집니다. 카카오에서 앱 연결을 해제하면 서버의 카카오 로그인 연결을 지웁니다. 카카오로만 가입한 계정은 로그인 상태를 끊되 계정 정보는 남으니, 삭제를 원하면 아래 이메일로 요청해 주세요. 캘린더 연결은 앱의 [연결 끊기]로 해제할 수 있고, Google 연결은 Google 계정 설정에서도 해제할 수 있습니다.

7. 이용자의 권리

이용자는 언제든지 자신의 개인정보를 조회, 수정, 삭제하도록 요청할 수 있습니다.
